# Detection Logs API

The detection logs resource stores snail detection data in two places:

- `detection_logs` in Postgres via TypeORM for the API source of truth.
- `snail-detected` in Supabase Storage for the uploaded image only.

The Nest app uses `synchronize: true`, so the `detection_logs` table is created automatically when the application starts.

## Entity shape

Each detection record stores these fields:

- `id`: UUID primary key generated by Postgres.
- `eventId`: unique client-generated identifier.
- `capturedAt`: ISO timestamp of the detection event.
- `eggClusterCount`: integer count from the client.
- `platform`: client platform, for example `android` or `ios`.
- `metadata`: normalized JSON payload from the client.
- `bucket`: Supabase bucket name. Default is `snail-detected`.
- `photoPath`: storage path of the uploaded image.
- `photoOriginalName`, `photoMimeType`, `photoSize`: uploaded file details.
- `createdAt`, `updatedAt`, `deletedAt`: lifecycle timestamps.

## Routes

Base path: `/api/detection-logs`

### Create

- Method: `POST`
- Content type: `multipart/form-data`
- File field: `photo`
- Max file size: `2 MB`

Form fields:

- `eventId`: string, required
- `capturedAt`: ISO-8601 string, required
- `eggClusterCount`: integer, required
- `platform`: string, required
- `metadata`: JSON string, required

Example:

```bash
curl -X POST http://localhost:3005/api/detection-logs \
  -H "Accept: application/json" \
  -F "photo=@./snail.jpg" \
  -F "eventId=event-123" \
  -F "capturedAt=2026-05-01T08:00:00.000Z" \
  -F "eggClusterCount=2" \
  -F "platform=android" \
  -F 'metadata={"metadata":{"platform":"android","deviceId":"cam-01"}}'
```

### Fetch all

- Method: `GET`
- Path: `/api/detection-logs`

Returns all non-deleted detection rows ordered by `capturedAt DESC`. Each item includes a signed `photoUrl` generated from Supabase Storage.

### Fetch one

- Method: `GET`
- Path: `/api/detection-logs/:eventId`

Returns one non-deleted detection row plus a signed `photoUrl`.

### Update

- Method: `PATCH`
- Path: `/api/detection-logs/:eventId`
- Content type: `application/json`

Accepted body fields are the same as create, but optional. `eventId` cannot be changed to a different value than the route parameter.

Example:

```json
{
  "eggClusterCount": 3,
  "platform": "android",
  "metadata": "{\"metadata\":{\"platform\":\"android\",\"reviewed\":true}}"
}
```

### Delete

- Method: `DELETE`
- Path: `/api/detection-logs/:eventId`

Soft-deletes the database row and removes the corresponding photo from Supabase Storage.

## Notes

- The API reads from Postgres, not by scanning the storage bucket.
- Storage only keeps the uploaded image. All metadata is stored in Postgres.
